As datas usam o horário de resposta reportado quando disponível; caso contrário, o horário de captura. Um turno compartilhado é uma associação, não prova de que uma ferramenta causou o uso de tokens. O contexto histórico permanece desconhecido. Busca, filtros, sinais e ordenação cobrem todas as respostas capturadas; as páginas mostram até 50. Os totais cobrem todo o escopo, incluindo cache. Os sinais marcam contexto ≥100k, saída ≥20k ou uso acima de 3× a média capturada após cinco chamadas. São pistas de investigação, não erros confirmados nem custos monetários. Uso ausente é desconhecido, nunca zero.
